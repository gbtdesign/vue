# 电商后台管理系统实施计划

## 项目现状

- **已就绪**: Vue 3.5 + Vue Router 5 + Pinia 4 + TypeScript 6 + Vite 8，核心栈完整
- **需安装**: Element Plus、@element-plus/icons-vue、echarts、vue-echarts
- **当前状态**: 脚手架初始模板，尚未进行业务开发

---

## 第一阶段：基础架构搭建

### 1.1 安装依赖并配置 Element Plus

- 安装 `element-plus`、`@element-plus/icons-vue`、`echarts`、`vue-echarts`
- 在 `src/main.ts` 中全局注册 Element Plus 和图标
- 在 `src/assets/main.css` 中引入 Element Plus 样式

### 1.2 构建后台管理布局

创建经典的后台管理布局框架：

- **新建** `src/layouts/AdminLayout.vue` — 后台主布局组件：
  - 左侧固定侧边栏（可折叠），包含系统 Logo 和菜单导航
  - 顶部 Header 栏，包含面包屑、用户头像、退出登录按钮
  - 右侧主内容区，嵌套 `<RouterView />` 展示子页面
- **新建** `src/layouts/components/Sidebar.vue` — 侧边栏菜单组件
- **新建** `src/layouts/components/Header.vue` — 顶部导航组件

### 1.3 路由体系重构

修改 `src/router/index.ts`，建立后台管理路由结构：

```
/login              -> LoginView（独立布局，无侧边栏）
/                   -> AdminLayout（后台主布局）
  /dashboard        -> DashboardView（数据仪表盘首页）
  /products         -> ProductListView（商品列表）
  /products/add     -> ProductEditView（新增商品）
  /products/:id/edit -> ProductEditView（编辑商品）
  /products/categories -> CategoryView（分类管理）
  /orders           -> OrderListView（订单列表）
  /orders/:id       -> OrderDetailView（订单详情）
  /users            -> UserListView（用户列表）
  /users/:id        -> UserDetailView（用户详情）
```

- 配置路由守卫（`beforeEach`），未登录时跳转 `/login`
- 使用路由懒加载优化首屏性能

## 执行顺序与依赖关系

```
第一阶段（基础架构）
  ├── 1.1 安装依赖 + 配置 Element Plus
  ├── 1.2 构建布局框架
  └── 1.3 路由重构
        ↓
第二阶段（登录） → 依赖第一阶段路由
        ↓
第三阶段（仪表盘） → 依赖布局和路由
        ↓
第四阶段（商品管理） → 可与第五、六阶段并行
第五阶段（订单管理） → 可与第四、六阶段并行
第六阶段（用户管理） → 可与第四、五阶段并行
        ↓
第七阶段（公共模块 + Mock + 收尾） → 贯穿全程，优先完成 request.ts 和 types
```

> 注：第七阶段中的 `api/request.ts`、`types/`、`utils/` 等公共模块应在第二阶段开始前就完成，因为后续所有模块都依赖这些基础设施。

## 技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| UI 框架 | Element Plus | 用户选择，Vue 3 生态最成熟 |
| 图表库 | ECharts + vue-echarts | 功能强大，适合数据可视化 |
| HTTP 请求 | axios | 行业标准，拦截器机制完善 |
| 状态管理 | Pinia（已有） | 项目已集成，继续使用 |
| 路由 | Vue Router 5（已有） | 项目已集成，继续使用 |
| 数据方案 | Mock 数据先行 | 前端独立开发，后续对接真实 API |
| CSS 方案 | Element Plus 内置 + 自定义变量 | 统一风格，减少自定义 CSS |
